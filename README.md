# GSAP Pinning Hero Sequence

A modern landing page template featuring GSAP ScrollTrigger pinning animations with a hero sequence, smooth scroll, and interactive elements.

## Features

- GSAP ScrollTrigger pinning animations
- Smooth scroll with Lenis
- Animated counters and stats
- Interactive FAQ accordion
- Responsive design with Tailwind CSS
- Next.js 14+ with TypeScript

## Tech Stack

- Next.js 14
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Tailwind CSS
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
